Terry's Restaurant API

Introduction

Terry's Restaurant API provides information about the restaurant menu.

The API uses the GET method to retrieve information. and the POST method to send new information to the server.

Get Menu

Method: GET

Endpoint:

/api/menu

Returns all available menu items.

GET Response Example

[
    {
        "id": 1,
        "name": "Spaghetti",
        "price": 200
    },
    {
        "id": 2,
        "name": "Empanadas",
        "price": 25
    },
    {
        "id": 3,
        "name": "Pizza",
        "price": 150
    }
]

Create Menu Item

Method: POST

Endpoint:

/api/menu

The POST method is used to send data to the server to create a new menu item.

POST Request Example

{
    "name": "Hamburger",
    "price": 120
}

HTTP Response

200 OK

The request was successful and the menu information was returned.

Request Flow

1. The client sends a GET request.

2. The server receives the request.

3. The API retrieves the menu information.

4. The server returns a JSON response.

HTTP Status Codes

200 OK

The request was successful. The server returned the requested information.

201 Created

A new resource, such as a menu item, was created successfully.

400 Bad Request

The request contains invalid data or cannot be processed because the information provided is incorrect.

404 Not Found

The requested resource or endpoint could not be found on the server.

500 Internal Server Error

An unexpected error occurred on the server while processing the request.
